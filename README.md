## 📝 Sobre o Projeto

A **Adega do Bahia** é uma landing page desenvolvida para apresentar a estrutura do estabelecimento. O objetivo principal do site é oferecer uma experiência intuitiva e agradável para os clientes, permitindo o acesso rápido a localização e canais de contato.

---

## 🚀 Tecnologias Utilizadas

O projeto foi desenvolvido do zero utilizando as seguintes tecnologias:

- **HTML5:** Estruturação semântica das páginas (`index.html`, `praia.html`, `salao.html`, `adega.html`).
- **CSS3:** Estilização visual personalizada (`style.css`) e layout responsivo adaptado para dispositivos móveis (`responsividade.css`).
- **JavaScript:** Funcionalidades interativas e dinâmica das páginas (`javascript.js`).
- **GitHub Pages:** Hospedagem direta do projeto.

---

## 🛠️ Como o Projeto Foi Desenvolvido

1. **Estrutura & Conteúdo:** Organização das seções em páginas dedicadas (Ambiente Praia, Salão principal, etc.).
2. **Design Responsivo:** Foco em garantir uma navegação fluida tanto em celulares quanto em desktops.
3. **SEO & Indexação:** Configuração de arquivos essenciais para motores de busca (`sitemap.xml` e `robots.txt`).
